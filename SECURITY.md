# Security

If you find security vulnerabilities, please discreetly report them to the repository owner. Please do not simply open pull-requests with security fixes or create issues, rather go to the "Security and Quality" tab on Github and press the green "Report a vulnerability" button to privately report it. If the button doesn't show, try navigating to the /security/advisories page of this repo. This link might take you there: [../../security/advisories](../../security/advisories)

## Note on AI usage related to security
Note that although AI usage is not welcome for this codebase, an exception is made for finding and reporting security vulnerabilities, for the simple reason that bad actors will not shy away from using it either. Please note that any implemented fixes for vulnerabilities should still be written by hand and not by an AI. However, you do not need to provide a fix in a report. A report on its own is strongly appreciated in every case.
