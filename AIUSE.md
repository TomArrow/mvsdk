# AI usage

This repository aims to not use any AI whatsoever. AI-generated code or AI-generated pull-requests or comments are not welcome.

However: For practical reasons it is acceptable to use AI for finding vulnerabilities *for the sole reason* of getting ahead of bad actors and discreetly and privately reporting them to the repository owners so they can be fixed. The fixes for these findings should still be done by hand, however reports do not need to include fixes. Please do not simply open pull-requests with security fixes, rather go to the "Security and Quality" tab on Github and press the green "Report a vulnerability" button to privately report it. If the button doesn't show, try navigating to the /security/advisories page of this repo. This link might take you there: [../../security/advisories](../../security/advisories)
